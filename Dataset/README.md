# Dataset do Gabaritei

Este branch tem só a versão atual do dataset: a **base de trabalho**, em `base_trabalho/`.
É a base usada pelo recomendador oficial (branch `recomendador`).

Versões anteriores (v1.2.1, v2, v2.1-rc1) e a base unificada do João ficam no branch
`wardrobe`, que guarda o histórico e nunca entra na `main`.

Para atualizar o dataset: substitua os arquivos em `base_trabalho/`, atualize o hash no
README dela e mova a versão anterior para o `wardrobe`.
