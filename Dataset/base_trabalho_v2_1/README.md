# Base de trabalho do recomendador v2.1

Este diretório guarda `gabaritei_recomendador_v2_1.zip`, a base de trabalho usada no desenvolvimento do recomendador v2.1.

O pacote contém a base curada `v1.2.1`, os artefatos TF-IDF e MiniLM da versão 2, o script de vetorização e o relatório de validação. Ele é mantido separado da candidata experimental `v2.1-rc1` e não substitui o experimento v2 congelado.

Antes de usar, extraia o ZIP em um diretório de trabalho e leia `RELATORIO_VALIDACAO.md`.
